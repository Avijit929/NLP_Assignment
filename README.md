This assignment shows how arrays (or list-like structures) work in **different memory allocation styles** using both **Python** and **C++**. It includes examples of four types of array behavior:

Types of Array Allocation

1. Fixed Stack Dynamic

   The array size is fixed and known at the time of writing the code. It is stored in temporary memory (stack).

2. Stack Dynamic

   The array size is decided while the program is running (runtime), but it still uses stack memory.

3. Fixed Heap Dynamic

   The array is stored in heap memory and has a fixed size, set during object creation.

4. Heap Dynamic

   The array is stored in heap memory and can grow or shrink while the program runs (like using `ArrayList` in Java or `vector` in C++).
